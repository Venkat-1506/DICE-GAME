# 🎲 Dice Rolling Game

A simple command-line Dice Rolling Game built with Python where the player competes against the computer. The game includes score tracking and stores match results using file handling for persistent statistics.

## ✨ Features

* 🎲 Random dice rolling for both player and computer
* 🏆 Automatic winner determination
* 📊 View cumulative game scores
* 💾 Persistent score storage using text files
* 🖥️ Menu-driven console interface

## 🛠️ Technologies Used

* Python 3
* File Handling
* Random Module

## 📁 Project Structure

```bash
Dice-Game/
│
├── main.py            # Main game logic and menu
├── dice.py            # Dice rolling functionality
├── score.py           # Score saving and retrieval
├── dice_score.txt     # Stores game results
├── .gitignore
```

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/dice-game.git
```

2. Navigate to the project folder:

```bash
cd dice-game
```

3. Run the application:

```bash
python main.py
```

## 🎮 Game Menu

```text
1. Play Game
2. View Score
3. Exit
```

* Select **Play Game** to roll the dice.
* Select **View Score** to see total wins, losses, and draws.
* Select **Exit** to quit the game.
